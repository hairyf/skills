# fabric.mod.json

Placed at the mod JAR's root; required for Fabric Loader to load the mod. It can also be generated by Loom's `FabricModJsonV1Task` or produced automatically for `include`d non-mod libraries.

## Mandatory Fields

```json
{
  "schemaVersion": 1,
  "id": "example-mod",
  "version": "1.0.0"
}
```

- `schemaVersion`: must be first, always `1`.
- `id`: 2–64 chars, starts with a letter, only ASCII letters/digits/`_`/`-`. Two mods with the same id are the same mod.
- `version`: preferably extended SemVer (any component count, `+build` metadata allowed).

## Metadata

- `name` (defaults to id), `description`.
- `contact`: `email`, `homepage`, `irc`, `issues`, `sources` (plus arbitrary extras like `discord`).
- `authors` / `contributors`: strings or `{ "name": ..., "contact": {...} }` objects.
- `license`: SPDX identifier(s).
- `icon`: PNG path, or a map of widths to paths.

## Loading

```json
{
  "environment": "*",
  "entrypoints": {
    "main": ["com.example.Mod"],
    "client": ["com.example.ModClient"],
    "server": ["com.example.ModServer"]
  },
  "jars": [{ "file": "nested/vendor/dependency.jar" }],
  "languageAdapters": { "kotlin": "net.fabricmc.language.kotlin.KotlinAdapter" },
  "mixins": ["example-mod.mixins.json", { "config": "example-mod.client.mixins.json", "environment": "client" }],
  "accessWidener": "example-mod.classtweaker",
  "provides": ["example_mod"]
}
```

- Entrypoints can be class names, `Class::method` references, or static fields. Other mods (e.g. Fabric API) can define additional entrypoints like `fabric-datagen`.
- `jars` nests dependencies (Loom's `include` fills this automatically); nested JAR paths are relative to the containing JAR.
- `provides` aliases other mod ids; if any provided id is requested, your mod is used instead.
- `accessWidener` points at a class tweaker file (see `class-tweakers`).

## Dependencies

```json
{
  "depends": {
    "fabricloader": ">=0.19.0",
    "minecraft": "~26.2",
    "java": ">=25",
    "fabric-api": "*"
  },
  "recommends": { "another-mod": "*" },
  "suggests": {},
  "breaks": {},
  "conflicts": {}
}
```

- `depends` / `breaks` crash on failure; `recommends` / `conflicts` warn.
- Values are version ranges (array = any range may match). Fabric supports extended SemVer: `26.1` == `26.1.0`, `1.2.3.4` valid, `+build` ignored for comparison.
- Useful range forms: exact `26.1.2`, `>26 <26.2`, `>=26.1 <26.2`, `~26.1` (same minor), `^26.2` (same major), `26.1.x`, `*`. Suffix `-` matches prereleases (e.g. `>26.2- <26.2` for 26.2 snapshots).
- Minecraft versions are normalized to SemVer (e.g. `26.1-snapshot-1` → `26.1-alpha.1`, `26w14a` → `26.1.1-alpha.26.14.a`).

## Custom Fields

Any data under `custom` is ignored by Loader — namespace your keys to avoid collisions.
