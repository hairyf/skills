# Registration

In 1.19.3+ registries live in `net.minecraft.registry` (`Registries`) and registration is `Registry.register(Registries.X, Identifier, value)`.

## Block + BlockItem

```java
public static final Block MY_BLOCK = Registry.register(
    Registries.BLOCK, new Identifier("mymod", "my_block"),
    new Block(Block.Settings.copy(Blocks.STONE).strength(2.0f)));

public static final Item MY_BLOCK_ITEM = Registry.register(
    Registries.ITEM, new Identifier("mymod", "my_block"),
    new BlockItem(MY_BLOCK, new Item.Settings()));
```

## Item

```java
public static final Item MY_ITEM = Registry.register(
    Registries.ITEM, new Identifier("mymod", "my_item"),
    new Item(new Item.Settings().maxCount(16)));
```

## Block entity

```java
public static final BlockEntityType<MyBlockEntity> MY_BE = Registry.register(
    Registries.BLOCK_ENTITY_TYPE, new Identifier("mymod", "my_be"),
    BlockEntityType.Builder.create(MyBlockEntity::new, MY_BLOCK).build());
```

The block's `createBlockEntity(pos, state)` must return `new MyBlockEntity(pos, state)`.

## Entity

```java
public static final EntityType<MyEntity> MY_ENTITY = Registry.register(
    Registries.ENTITY_TYPE, new Identifier("mymod", "my_entity"),
    EntityType.Builder.create(MyEntity::new, SpawnGroup.MONSTER)
        .setDimensions(0.6f, 1.8f).build());

// Register default attributes (common side)
FabricDefaultAttributeRegistry.register(MY_ENTITY, MyEntity.createMobAttributes());
```

Client rendering is registered separately (see features-client).

## Sound event

```java
public static final SoundEvent MY_SOUND = Registry.register(
    Registries.SOUND_EVENT, new Identifier("mymod", "my_sound"),
    SoundEvent.of(new Identifier("mymod", "my_sound")));
```

Also add a `sounds.json` under `assets/<modid>/` mapping the event to a `.ogg` file.

## Creative tab

```java
Registry.register(Registries.ITEM_GROUP, new Identifier("mymod", "group"),
    FabricItemGroup.builder().icon(() -> new ItemStack(MY_ITEM))
        .entries(c -> { c.add(MY_ITEM); c.add(MY_BLOCK); }).build());
```

## Key points

- Use `Identifier("modid", "path")` — the mod id must match `fabric.mod.json`.
- Register everything exactly once, in a static `init()` called from the mod initializer.
- Textures/models are **not** auto-generated by registration — provide them under `assets/<modid>/` or use datagen.
- `FabricDefaultAttributeRegistry` is from `net.fabricmc.fabric.api.object.builder.v1.entity` (fabric-object-builder-api).
