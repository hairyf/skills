# Project Structure

## Top-Level Layout

| Path | Purpose |
|------|---------|
| `src/` | Main source; Vite `root` is `src/`. |
| `extension/` | Extension package root: built assets, generated `manifest.json`, static assets. Load this folder in the browser. |
| `scripts/` | Dev/build helpers: `manifest.ts`, `prepare.ts`, `utils.ts`. |

## `src/` Breakdown

| Path | Purpose |
|------|---------|
| `manifest.ts` | Defines dynamic manifest (MV3, permissions, content_scripts, popup/options/sidepanel paths). Not the built entry; consumed by `scripts/manifest.ts`. |
| `background/main.ts` | Background/service worker entry; built by `vite.config.background.mts`. |
| `contentScripts/index.ts` | Content script entry; built by `vite.config.content.mts`. Injects Vue app into page (e.g. shadow DOM). |
| `popup/`, `options/`, `sidepanel/` | Each has `index.html` + `main.ts` + root Vue component; built as multi-entry from main Vite config. |
| `components/` | Auto-imported Vue components (unplugin-vue-components); shared across popup, options, sidepanel, content script. |
| `composables/` | e.g. `useWebExtensionStorage`; shared where applicable. |
| `logic/` | Shared app logic: `common-setup.ts` (setupApp), `storage.ts`, `index.ts`. |
| `styles/` | Shared CSS; imported from popup/options/sidepanel entries. |
| `assets/` | Static assets for Vue (e.g. images). |
| `env.ts` | Runtime helpers (e.g. `isForbiddenUrl`, `isFirefox`). |

## `extension/` After Build

| Path | Purpose |
|------|---------|
| `manifest.json` | Generated by `scripts/manifest.ts` from `getManifest()`. |
| `dist/` | Built outputs: `popup/`, `options/`, `sidepanel/`, `background/`, `contentScripts/`. |
| `assets/` | Static extension assets (e.g. icons) referenced in manifest. |

## Scripts (package.json)

- **dev**: `clear` → `run-p dev:*` (prepare, background, web, js). Prepare writes manifest + stub HTML; Vite serves and builds.
- **build**: `clear` → `build:web` → `build:prepare` → `build:background` → `build:js`. Prepare runs again to emit final manifest and stubs.
- **Load extension**: Use the `extension/` directory in browser (Chrome: Extensions → Load unpacked; Firefox: about:debugging).

## Key Points

- All HTML entries (popup, options, sidepanel) live under `src/`; build output goes to `extension/dist/<entry>/`.
- Background and content scripts are library builds (IIFE) with their own Vite configs; output filenames (`index.mjs`, `index.global.js`) are fixed for manifest.
- Alias `~/` resolves to `src/` for imports.
