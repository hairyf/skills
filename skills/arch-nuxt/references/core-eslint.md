# ESLint (eslint.config.js)

Linting uses flat config: `@antfu/eslint-config` as base, then Nuxt’s generated config appended. Enables UnoCSS, formatters, and pnpm awareness.

## Usage

```js
// eslint.config.js
// @ts-check
import antfu from '@antfu/eslint-config'
import nuxt from './.nuxt/eslint.config.mjs'

export default antfu(
  {
    unocss: true,
    formatters: true,
    pnpm: true,
  },
)
  .append(nuxt())
```

## Key points

- **@antfu/eslint-config** — Base rules; pass options for unocss (UnoCSS class name lint), formatters, and pnpm (pnpm workspace awareness).
- **Nuxt config** — `.nuxt/eslint.config.mjs` is generated by Nuxt; append it so Nuxt-specific rules and globals (e.g. auto-imports) are applied. Run `nuxt prepare` or dev/build so `.nuxt` exists.
- **Module** — `@nuxt/eslint` in `nuxt.config.ts` wires ESLint to the Nuxt toolchain; keep `eslint.config.js` at project root and append the generated config.
- **Script** — Use `pnpm lint` (e.g. `eslint .`) to run lint; typecheck separately with `pnpm typecheck`.
